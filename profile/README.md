### 🐥 [PICore](https://github.com/BaptisteLOpenSource/PICore)

Project Intelligence Core : un index local de tes projets git et de leurs worktrees.
Vérifie ton accès git et GitHub, ne nettoie que les worktrees fusionnés et propres, et fournit un
contexte condensé aux agents IA via MCP. Pas de télémétrie. Statut : pré-alpha.
